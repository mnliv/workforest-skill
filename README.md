# workforest-skill (archived)

**This repo is archived.** The skill content now lives directly in the
[`workforest`](https://github.com/mnliv/workforest) repo itself, at
[`skill/workforest/`](https://github.com/mnliv/workforest/tree/main/skill/workforest) —
kept version-consistent with the CLI it ships alongside, instead of a
separate repo that had to be manually synced.

## Install the skill

```bash
npm install -g @mnliv/workforest
workforest skill install --provider claude
```

See the [main repo's README](https://github.com/mnliv/workforest#using-with-a-coding-agent)
for details, and open issues or PRs there — this repo no longer accepts
changes.
